# Section 6 · Required-Documents Matrix

This section summarises the documents required for each claim type. A claim missing any required document is **not rejected and not approved** — the correct action is to **request the missing documents** from the customer (Clause 0.2(d)).

| Claim type | Required documents |
|---|---|
| Health — inpatient | medical report, itemised hospital invoice, member ID |
| Health — medication | prescription, pharmacy invoice, member ID |
| Health — diagnostics | referring physician request, itemised invoice, member ID |
| Motor — collision (own damage) | photos, repair estimate, driver's licence, vehicle registration |
| Motor — theft | police theft report, spare key, vehicle registration |
| Motor — third-party | police report, photos, third-party details |
| Property — fire/damage | photos, itemised list, repair/replacement quotes |
| Property — theft | police report (forced entry), itemised list, proof of ownership |
| Travel — medical | physician report, itemised invoices |
| Travel — cancellation | proof of covered reason (medical/death certificate or official notice) |
| Travel — baggage | airline PIR or police report, receipts/proof of ownership |

**Clause 6.1 — Partial documents.** If some but not all required documents are present, list exactly which are missing and request them. Do not guess the missing values.

**Clause 6.2 — Proof of amount.** Any monetary claim needs an invoice, estimate, or receipt supporting the amount. An amount with no supporting document is treated as a missing document and, if it sits just under the cap, also a fraud-risk indicator (Clause 0.6(c)).
